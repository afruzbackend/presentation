Task Manager va tizim boshqaruv vositalari bilan ishlash

Slaydlarda Chop etish

Maqsad: O‘quvchilarga Task Manager, Resource Monitor va System Information vositalari yordamida kompyuter yuklamasini kuzatish, javob bermayotgan dasturlarni yopish va avtoyuklanishni boshqarish bo‘yicha amaliy ko‘nikmalar berish.

Reja:
  1. Task manager oynasi tuzilishi: jarayonlar va unumdorlik ko‘rsatkichlari
  2. Avtoyuklanish, javob bermayotgan dasturlarni yopish va resource monitor, msinfo32 vositalari

1. Task manager oynasi tuzilishi: jarayonlar va unumdorlik ko‘rsatkichlari

Kerakli jihozlar va xavfsizlik

Mashg‘ulot uchun Windows 10 yoki 11 o‘rnatilgan kompyuter, foydalanuvchi hisobi va natijalarni yozish varag‘i kerak. Xavfsizlik eslatmasi: «Windows processes» guruhidagi tizim jarayonlarini (csrss.exe, winlogon.exe, svchost.exe, lsass.exe) majburan yopish taqiqlanadi — bu tizimning qotib qolishi yoki to‘satdan qayta yuklanishiga olib keladi. Saqlanmagan ishlar bo‘lsa, avval ularni saqlang.

Task Manager’ni ochish usullari

  • Ctrl + Shift + Esc — eng tez usul, to‘g‘ridan-to‘g‘ri ochiladi.
  • Ctrl + Alt + Delete → «Task Manager» bandi.
  • Win + X menyusi → «Task Manager».
  • Win + R → taskmgr → Enter.

Agar oyna kichik ko‘rinishda ochilsa, «More details» (Batafsil) tugmasini bosing. Windows 11 da bo‘limlar oynaning chap tomonidagi menyuda joylashgan.

2. Avtoyuklanish, javob bermayotgan dasturlarni yopish va resource monitor, msinfo32 vositalari

Javob bermayotgan dasturni yopish

  • Processes bo‘limida «Not responding» (Javob bermayapti) yozuvli ilovani toping.
  • Unga sichqonchaning o‘ng tugmasi bilan bosing va «End task» (Vazifani tugatish) ni tanlang.
  • Agar ish stoli va panel qotib qolgan bo‘lsa, «Windows Explorer» jarayonini tanlab, «Restart» tugmasini bosing — Explorer qayta ishga tushadi.
  • Jarayon qayta-qayta osilsa, uni yangilash yoki qayta o‘rnatish zarurligini qayd eting.

Performance bo‘limidan ma’lumot olish

Performance bo‘limida CPU sahifasi protsessor modeli, bazaviy chastota, yadro (Cores) va mantiqiy protsessorlar (Logical processors) soni, tizim ishlagan vaqt (Up time) ni ko‘rsatadi. Memory sahifasida umumiy va band xotira, xotira tezligi (Speed) va band slotlar (Slots used) soni beriladi. Disk sahifasida «Active time» doimiy 100 % bo‘lib tursa, disk tizimning «tor joyi» ekanidan dalolat beradi.

Avtoyuklanishni boshqarish

  • Startup apps bo‘limini oching va «Startup impact» ustuni bo‘yicha saralang.
  • «High» ta’sirli dasturlar ro‘yxatini ko‘rib chiqing (masalan, messenjerlar, o‘yin platformalari, yangilovchi dasturlar).
  • Keraksiz dasturga o‘ng tugma bilan bosib «Disable» ni tanlang. Antivirus va drayver panellarini o‘chirmang.
  • Kompyuterni qayta yuklab, yuklanish tezligi o‘zgarganini kuzating.

Dasturni avtoyuklanishdan o‘chirish uni kompyuterdan o‘chirmaydi — u faqat Windows bilan birga o‘zi ishga tushmaydi.

3. Amaliy mashq: kompyuter yuklamasini tahlil qilib, avtoyuklanishni optimallashtirish

Qo‘shimcha vositalar

  • Resource Monitor (Win + R → resmon): qaysi jarayon qaysi faylni o‘qiyotgani, qaysi tarmoq manziliga ulanayotganini batafsil ko‘rsatadi.
  • System Information (Win + R → msinfo32): OT versiyasi, BIOS versiyasi va rejimi (UEFI yoki Legacy), protsessor, xotira hajmi haqida yig‘ma ma’lumot.
  • Performance Monitor (perfmon): ko‘rsatkichlarni uzoq vaqt kuzatish va hisobot tuzish.

Natijani tekshirish

Mashq to‘g‘ri bajarilganini quyidagicha tekshiring: qayd varag‘idagi protsessor va xotira ma’lumotlari msinfo32 dagi ma’lumotlar bilan mos kelishi kerak; o‘chirilgan dasturlar Startup apps ro‘yxatida «Disabled» holatida ko‘rinishi kerak; qayta yuklashdan keyin tizim barqaror ishlashi lozim.

AMALIY TOPSHIRIQ

Har bir o‘quvchi o‘z kompyuterida Task Manager’ni ochib, protsessor, xotira va diskni eng ko‘p yuklayotgan 3 ta jarayonni aniqlaydi va qayd etadi. So‘ngra Performance bo‘limidan protsessor modeli, yadrolar soni, tezkor xotira hajmi va band slotlar sonini yozib oladi. Startup apps bo‘limida «High» ta’sirli keraksiz dasturlarni o‘qituvchi ruxsati bilan o‘chiradi va qayta yuklashdan keyingi farqni izohlaydi. Baholash: ma’lumotlar to‘g‘riligi, tizim jarayonlariga tegilmagani va xulosalarning asoslanganligiga qarab.
